# Cleanup recommendations

Generated after the 2.0 reorganization pass. Nothing in this list was
deleted automatically — everything you'd remove is your call. Each
section ranks recommendations by safety: **green** = safe to delete
right now, **yellow** = think before you delete, **red** = don't unless
you know why.

## 🟢 Safe to delete

These are all generated artifacts, runtime data, or pre-2.0 files that
have no inbound references and that your `.gitignore` already covers
(meaning they shouldn't be in version control anyway).

### Generated build artifacts

| Path | Why it's safe | Regenerated by |
|---|---|---|
| `htmlcov/` | pytest-cov HTML report. Already gitignored. | `pytest --cov` |
| `.coverage` | pytest binary coverage state. Already gitignored. | `pytest --cov` |
| `.pytest_cache/` | pytest's internal cache. Already gitignored. | `pytest` |
| `dash_improve_my_llms.egg-info/` | setuptools metadata. Already gitignored. | `python -m build` |
| `__pycache__/` (all of them) | Python bytecode cache. Already gitignored. | Python on import |
| `visitor_analytics.json` | Demo app's runtime data. Now gitignored (added this pass). | `app.py` on first request |

```bash
# Remove all at once:
rm -rf htmlcov/ .coverage .pytest_cache/ dash_improve_my_llms.egg-info/
find . -type d -name __pycache__ -not -path "./.venv/*" -exec rm -rf {} +
rm -f visitor_analytics.json
```

After removing, optionally `git rm --cached` any of these that were
already tracked (the gitignore catches new ones but doesn't untrack
existing ones).

## Verifying after cleanup

After deleting any of the above, the green-path verification is:

```bash
# 1. Tests still pass
pytest tests/ --ignore=tests/legacy --tb=short -q

# 2. Demo app still imports clean
python -c "
import importlib.util, dash
dash.Dash.run = lambda *a, **k: None
spec = importlib.util.spec_from_file_location('app', 'app.py')
mod = importlib.util.module_from_spec(spec)
spec.loader.exec_module(mod)
"

# 3. Build still succeeds
python -m build
```

If all three are green, the cleanup didn't break anything.
